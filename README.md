# Ziphus - decode Engine

A minimalistic, lightweight translator for Morse code, binary, and custom shift ciphers that runs in your browse,with an option to swap the encoding with decoding.

## What it can do

* **Morse Code:** Converts text into morse code signals and back.
* **8-Bit Binary:** 8-bit binary streams decodes readable text or encode to binary.
* **Caesar Cipher:** Configurable shift cipher where you can set your own custom shift key.
* **Atbash Cipher:** Automatically reverses the alphabet for fast monoalphabetic substitution.
* **Vigenere Cipher:** Polyalphabetic cipher using a custom text key.

## Built with

* HTML5
* CSS3
* Plain JavaScript (Vanilla JS)

## How to run it locally

1. Clone or download this repository.
2. Open `index.html` in any web browser. No dependencies or build steps required.
