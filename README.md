# ZIPHUS_

A lightweight, terminal-styled signal translator and encryption engine that converts plain text into Morse code, 8-bit binary streams, and shift ciphers locally in your browser.


 **[Try CIPHUS Live]https://aqvoz.github.io/Ziphus/**

## Quick Start
Open the live demo link above to launch the terminal interface immediately in your web browser—no setup or installation required.

## Features
* **Morse Code Signal:** Translates standard alphanumeric characters into standardized dots and dashes (`. / -`).
* **8-Bit Binary Stream:** Converts raw text into 8-bit computer binary strings.
* **Cyber-Shift Cipher:** Encrypts messages using a Caesar shift (+3 character offset).
* **Live Processing:** Updates translation, output mode tags, and character counts instantly on input.
* **Clipboard Integration:** One-click signal copying with visual confirmation feedback.
