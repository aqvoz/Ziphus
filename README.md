## Ziphus-Siginal Engine
-A clean,lightweight terminal style translator for morse code,binary and custom shift cipher 

## What it can do
-**Morse code:**Converts text into morse code siginals and back
-**8 Bit binary:**Encodes text into 8 bit binary streams and back   
-**Ceasar Cipher:**configurable shift cipher where u can set your own shift decode or encode

## Built with
- HTML5
- CSS3 (Custom Dark Terminal Theme)
- Plain JavaScript (Vanilla js)

## How to run it Locally  
Open index.html in any web broswer
